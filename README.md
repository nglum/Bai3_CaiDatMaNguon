# Hệ Thống Quản Lý và Đặt Vé Phim Trực Tuyến (Cine-Ticket Booking System)

Dự án bài tập lớn môn Công nghệ Phần mềm: Xây dựng website quản lý và đặt vé xem phim.

## Công nghệ
- Frontend: HTML, CSS, JavaScript
- Backend: PHP
- Database: MySQL

## Cấu trúc dự án
```
cine-ticket-booking/
├── index.php
├── config/
│   └── database.php
├── pages/
├── api/
├── assets/
└── database.sql
```

## Khởi động
1. Tạo database từ file `database.sql`
2. Cập nhật thông tin kết nối DB trong `config/database.php`
3. Chạy server PHP
